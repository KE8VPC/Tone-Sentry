# Tone Sentry 0.8.17

Google Chat incoming-webhook notifications: explicit google_chat or automatic URL recognition, multiline message template, unsent preview, optional transcripts and HTTPS recording links. Existing agency filters, delivery retries and FTP completion dependency apply. Google-specific controls appear only for Google Chat. No OpsHub dependency. No live messages were sent during development.

See docs/GOOGLE-CHAT.md and the in-app Help & how to for setup. Close the previous executable before launching this build against the existing data folder. Existing settings and accounts are preserved. Google Chat is optional and not enabled automatically.

This release does not implement notify-only beeps, OpenWhispr transcription, or discovery/known-recording association. These remain future work.
